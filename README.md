# Proyek Analisis Data: Air Quality Dataset (Nongzhanguan)

## Deskripsi
Proyek ini merupakan analisis data kualitas udara di Stasiun Nongzhanguan periode 2013–2017. Analisis ini bertujuan untuk memahami tren bulanan konsentrasi polutan PM2.5 dan PM10 serta pola distribusi harian (diurnal) PM2.5 guna memberikan rekomendasi tindakan mitigasi polusi bagi masyarakat dan pemerintah lokal.
